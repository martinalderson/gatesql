Every query needs a reason

Agents must declare why they're running each query. No purpose, no results. Full stop.

Allowed
/* <agent_purpose>check low-stock items for reorder alert</agent_purpose> */
SELECT product, qty FROM inventory WHERE qty < 10;
Rejected
SELECT * FROM users;
ERROR: query rejected — missing purpose comment

Every purpose is logged with the query, agent ID, and session. You get a full audit trail of not just what an agent did, but why it said it needed to.

Built for agent workloads

Short-lived JWTs

Parent creates a session, gets a JWT with hard expiry. Agent never sees real database credentials.

Purpose enforcement

Every query must include a purpose comment. Queries without one are rejected. Internal driver queries are exempt.

Query budgets

Set a max query count per session. When the budget is exhausted, the connection is closed.

Idle timeout

Sliding-window idle timeout with configurable duration. Plus a hard cap on total session lifetime.

Full audit log

JSON-lines query logs with agent ID, session ID, purpose, query text, and timing. Every query attributed.

Zero-alloc relay

ArrayPool + Span in the hot path. Flush at sync points only. ~986 TPS through the proxy at 2.8x overhead.

Admin API

Create, list, and revoke sessions over HTTP. API-key authenticated. Build it into your agent orchestration.

Live dashboard

MVC dashboard shows active sessions, query counts, and connection status at a glance.

Standard clients

Agents connect with psql, Npgsql, asyncpg, or any PostgreSQL client. No custom SDK required.

Quick start

# Point at your PostgreSQL, set an API key

$ docker run -p 15432:15432 -p 8080:8080 \

  -e GATESQL_UPSTREAM_HOST=my-pg.example.com \

  -e GATESQL_UPSTREAM_PASSWORD=secret \

  -e GATESQL_API_KEY=pk_prod_abc123 \

  gatesql/gatesql

→ Proxy listening on :15432, dashboard on :8080


# Create a session for your agent

$ curl -X POST http://localhost:8080/api/sessions \

  -H "X-Api-Key: pk_prod_abc123" \

  -d '{"agentId":"my-agent","task":"inventory-check"}'

→ {"token":"eyJhbG...","sessionId":"..."}


# Agent connects with the JWT as password

$ PGPASSWORD="eyJhbG..." psql -h 127.0.0.1 -p 15432 -U agent -d postgres
